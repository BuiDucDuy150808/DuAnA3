
# WEBSITE CỬA HÀNG HOA QUẢ

## 1. Giới thiệu dự án

Đây là website giới thiệu và kinh doanh các sản phẩm hoa quả, được xây dựng trong quá trình thực hiện bài tập lớn môn học.

Website giúp khách hàng tìm hiểu thông tin cửa hàng, xem các sản phẩm và gửi thông tin liên hệ thông qua biểu mẫu đặt hàng.

## 2. Công nghệ sử dụng

- HTML5: Xây dựng nội dung và cấu trúc website
- CSS3: Thiết kế giao diện và bố cục trang web

## 3. Cấu trúc thư mục

```text
DuAnA3/
│
├── assets
├── AI_LOG.md
├── CHANGELOG.md
├── css.css
├── index.html
├── README.md
└── RELEASE.md
```

## 4. Cách chạy website

1. Tải hoặc sao chép mã nguồn dự án về máy tính
2. Mở thư mục dự án bằng Visual Studio Code
3. Mở file `index.html`
4. Sử dụng trình duyệt để xem website

Có thể sử dụng tiện ích Live Server trong Visual Studio Code để chạy website thuận tiện hơn.

## 5. Các chức năng chính

- Giới thiệu thông tin cửa hàng
- Hiển thị danh sách sản phẩm
- Trình bày hình ảnh và thông tin sản phẩm
- Biểu mẫu liên hệ và đặt hàng
- Điều hướng giữa các khu vực trên website

## 6. Phạm vi dự án

Đây là website tĩnh được xây dựng bằng HTML và CSS.

Website chưa tích hợp cơ sở dữ liệu, hệ thống quản lý đơn hàng hoặc thanh toán trực tuyến.
